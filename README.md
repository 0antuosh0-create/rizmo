## 📚 ویژگی‌های برجسته سامانه

- 📘 **بانک جامع ۴۲ مسئله تشریحی با مراجع معتبر ایرانی و کنکوری:**
  - **فصل اول: آنالیز فوریه (Fourier Analysis):** ۱۴ مسئله تشریحی (سری فوریه، بسط‌های نیم‌دامنه، فرم مختلط، تساوی پارسوال، انتگرال و تبدیل فوریه).
  - **فصل دوم: معادلات دیفرانسیل با مشتقات جزئی (PDEs):** ۱۴ مسئله تشریحی (دسته‌بندی، جداسازی متغیرها، معادله موج ۱ بعدی و دالامبر، معادله حرارت میله متناهی/نامتناهی، معادله لاپلاس در مختصات دکارتی و قطبی).
  - **فصل سوم: متغیرها و توابع مختلط (Complex Analysis):** ۱۴ مسئله تشریحی (معادلات کوشی-ریمان، توابع همساز و مزدوج، فرمول انتگرال کوشی، سری تیلور و لوران، قضیه مانده‌ها و انتگرال‌های حقیقی).
- 🏷️ **منبع‌دهی دقیق و دانشگاهی به ازای تک‌تک سوالات:**
  - کتاب ریاضیات مهندسی دکتر عبدالله شیدفر (انتشارات دالاهو)
  - کتاب ریاضی مهندسی دکتر معتقدی / انتشارات پارسه و پوران پژوهش
  - کتاب ریاضی مهندسی دکتر مسعود آقاسی (انتشارات نگاه دانش)
  - سوالات میان‌ترم و پایان‌ترم دانشگاه صنعتی شریف، دانشگاه تهران، صنعتی امیرکبیر، علم و صنعت و فردوسی مشهد
  - سوالات آزمون سراسری کارشناسی ارشد مهندسی برق و مکانیک (سال‌های ۱۳۹۷ تا ۱۴۰۲)
  - مراجع استاندارد کریزیگ (Advanced Engineering Mathematics) و متغیرهای مختلط چرچیل و براون
- 💡 **امکانات اختصاصی هر کارت مسئله:**
  - فیلتر بر اساس سطح دشواری (`آسان`, `متوسط`, `سخت`), زیرمبحث، دسته‌بندی منبع و وضعیت مطالعه با منوهای شناور سفارشی.
  - **راهنمایی گام آغازین (Hint Toggle):** نمایش ایده اولیه و فرمول راهگشا بدون لو رفتن پاسخ.
  - **جعبه هشدار تله امتحانی (Exam Trap):** تذکر مهم‌ترین اشتباهات محاسباتی متداول دانشجویان در امتحانات.
  - **آکاردئون پاسخ تشریحی گام‌به‌گام:** نمایش مراحل حل با شماره‌گذاری (`گام ۱`, `گام ۲`, ...) و استنتاج کامل ریاضی با KaTeX.
  - ذخیره‌سازی پیشرفت مطالعه و نشان‌شده‌ها (Bookmarks) در `localStorage`.
- 🎓 **مرکز آزمون‌های خودسنجی تستی (Exam Center):**
  - ۱۰ تست محاسباتی و مفهومی به ازای هر فصل (مجموعاً ۳۰ تست).
  - تایمر آزمون، ثبت پاسخ‌ها، درصدگیری، و کارنامه ارزیابی با بازخورد آنی.
  - تحلیل تشریحی گام‌به‌گام برای تمام گزینه‌ها و دام‌های تستی پس از ثبت نهایی.
- ⚡ **فرمول‌نامه سریع و اطلس قضایا (Cheat Sheet):**
  - خلاصه دسته‌بندی‌شده مهم‌ترین فرمول‌های امتحانی با قابلیت کپی مستقیم کدهای $\LaTeX$.
- 🔬 **شبیه‌سازهای بصری تعاملی (Interactive Math Visualizers):**
  - **شبیه‌ساز سنتز هارمونیک فوریه:** مشاهده زنده ترکیب فرکانس‌های سینوسی و پدیده جهش گیبس (Gibbs Phenomenon) روی امواج مربعی، دندان‌اره‌ای و مثلثی.
  - **شبیه‌ساز معادلات PDE:** پویانمایی زمان-مکان میرایی نمایی معادله حرارت و ارتعاشات تار مرتعش در شرایط مرزی دیریکله و نویمان (عایق).
  - **کاوشگر صفحه مختلط و کانتور مانده‌ها:** کشیدن و تغییر شعاع کانتور دایره‌ای، تشخیص قطب‌های محصور و محاسبه بلادرنگ $\oint_C f(z) dz = 2\pi i \sum \text{Res}$.
- 🌓 **تم دوگانه تیره (Dark Mode پیش‌فرض) و روشن (Light Mode):**
  - پالت رنگی آمیتیست و زمرد با کنتراست استاندارد و محافظ چشم.
  - تایپوگرافی اصیل فارسی با فونت استاندارد **وزیرمتن (Vazirmatn)** و رندر فرمول‌ها با **KaTeX**.
- 🔍 **جستجوی پیش‌بینی‌کننده با کلید میانبر (`Ctrl + K` یا `/`):**
  - جستجوی بلادرنگ در تمام مسائل، فرمول‌ها و مراجع علمی.

## 🚀 راهنمای نصب و اجرای محلی

```bash
# کلون مخزن
git clone https://github.com/0antuosh0-create/rizmo.git
cd rizmo

# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه
npm run dev

# ساخت نسخه نهایی
npm run build
```
